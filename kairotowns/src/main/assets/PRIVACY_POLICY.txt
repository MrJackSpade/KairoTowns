KairoTowns Privacy Policy
Last updated: October 22, 2026

KairoTowns is an Android FM Towns emulator published by Loxifi LLC. This policy covers KairoTowns. For privacy questions or requests, email admin@loxifi.com.

Data on your device
KairoTowns reads the game files and folders and any firmware files that you choose through Android's file picker, and games that another app asks it to open. It uses file contents to identify supported games. Game files, file names, content hashes, imported firmware, save states, settings, and downloaded images stay on your device in the selected folder or the app's private storage. Loxifi does not receive these files, names, hashes, or settings. KairoTowns has no account, advertising, analytics, or crash reporting service.

Optional artwork downloads
The standard edition does not bundle artwork. If you choose "Download missing images" or tap an image to request a larger version, KairoTowns makes an HTTPS request directly to images.launchbox-app.com, gamesdb-images.launchbox.gg or raw.githubusercontent.com. The requested image URL can reveal which game's artwork was requested. The image service also receives your network IP address and ordinary request information needed to deliver the image. KairoTowns does not send your game files, file names, firmware, or content hashes to these services, and Loxifi does not receive their request logs. The services control their own logging and retention. Downloaded images are stored on your device.

Catalog updates
When KairoTowns checks for catalog updates, it requests the latest catalog over HTTPS from raw.githubusercontent.com, which hosts the Kairo projects' catalogs. The request sends ordinary network information, including your IP address, to that service. It does not send your game files, file names, or content hashes. The hosting service controls its own logs and retention.

Update checks
When KairoTowns starts, it requests the list of KairoTowns's releases over HTTPS from api.github.com to see whether a newer version is available. The request sends ordinary network information, including your IP address, to GitHub. It does not send your game files, file names, or content hashes. GitHub controls its own logs and retention.

Imported catalog files
When you import a catalog file, a copy of its metadata, artwork and update address is stored privately on your device. Checking installed catalogs contacts only the update addresses supplied by those installed files over HTTPS. Those servers receive your IP address and ordinary request information, but not your game files, library names or content hashes. The servers control their own logs and retention. Removing a catalog deletes its imported metadata and artwork, while keeping your games and personal overrides.

Storage, security, and deletion
KairoTowns accesses files only after you select them with Android's file picker or another app asks it to open them. It stores app data in private app storage, does not enable Android app backup, and uses HTTPS for every network request. Local app data remains until you clear KairoTowns's storage or uninstall it; that does not remove original game files in your chosen folder. If you use a game's Delete action and confirm, KairoTowns deletes that game's file from your chosen folder. Loxifi has no server copy of app data to delete. To ask about data sent to an image or hosting service, contact that service.

Support correspondence
If you email Loxifi for support, we receive your email address and the information you choose to send and use it to respond. Email admin@loxifi.com to request deletion of that correspondence.

Changes
We may update this policy when KairoTowns's behavior changes. The current version will be available in the app.
