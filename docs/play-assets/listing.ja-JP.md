# Google Play listing: Japanese (ja-JP)

- **App name:** KairoTowns

## Short description

Android で、お手持ちの FM Towns ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

KairoTowns は、お手持ちの FM Towns ゲームを Android で遊べるアプリです。CD イメージやディスクイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（FM Towns キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームと FM Towns BIOS は含まれていません。一部のゲームには追加の設定が必要です。

同じアプリを KairoTowns の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

KairoTowns は、Soji Yamakawa 氏による FM Towns エミュレーター Tsugaru を使った独立したプロジェクトです。
