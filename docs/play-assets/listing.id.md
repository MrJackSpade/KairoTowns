# Google Play listing: Indonesian (id)

- **App name:** KairoTowns

## Short description

Mainkan game FM Towns Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

KairoTowns memungkinkan Anda memainkan game FM Towns milik Anda sendiri di Android. Tambahkan image CD dan disk Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard FM Towns. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game dan BIOS FM Towns tidak disertakan. Beberapa game memerlukan pengaturan tambahan.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases KairoTowns. Versi Google Play memiliki fitur yang sama.

KairoTowns adalah proyek independen yang menggunakan Tsugaru, emulator FM Towns karya Soji Yamakawa.
