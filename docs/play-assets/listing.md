## Short description

Play your FM Towns games on Android with touch controls or a gamepad.

## Full description

KairoTowns lets you play your own FM Towns games on Android. Add your CD and disk images, pick a game from the library, and play with a gamepad or on-screen controls, including an FM Towns keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games and the FM Towns BIOS aren't included. Some games need extra setup.

You can also download the same app free from KairoTowns GitHub Releases. The Play version has the same features.

KairoTowns is an independent project using Tsugaru, the FM Towns emulator by Soji Yamakawa.
