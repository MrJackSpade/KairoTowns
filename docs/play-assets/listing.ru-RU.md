# Google Play listing: Russian (ru-RU)

- **App name:** KairoTowns

## Short description

Играйте в игры для FM Towns на Android с сенсорным управлением или геймпадом.

## Full description

KairoTowns позволяет играть в ваши собственные игры для FM Towns на Android. Добавьте свои образы CD и дисков, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру FM Towns. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры и BIOS FM Towns не входят в комплект. Некоторым играм нужна дополнительная настройка.

Это же приложение можно бесплатно скачать в GitHub Releases KairoTowns. В версии из Google Play те же возможности.

KairoTowns — независимый проект на основе Tsugaru, эмулятора FM Towns от Soji Yamakawa.
