# Google Play listing: German (de-DE)

- **App name:** KairoTowns

## Short description

Spielen Sie Ihre FM-Towns-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit KairoTowns spielen Sie Ihre eigenen FM-Towns-Spiele auf Android. Fügen Sie Ihre CD- und Diskettenabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer FM-Towns-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele und das FM-Towns-BIOS sind nicht enthalten. Manche Spiele brauchen eine zusätzliche Einrichtung.

Sie können dieselbe App auch kostenlos über die GitHub Releases von KairoTowns herunterladen. Die Version bei Google Play hat dieselben Funktionen.

KairoTowns ist ein unabhängiges Projekt auf Basis von Tsugaru, dem FM-Towns-Emulator von Soji Yamakawa.
