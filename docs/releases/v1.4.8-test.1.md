# v1.4.8-test.1

Test build of KairoTowns, for FM Towns games. It is not published to Google Play.

- The D-pad always sends the arrow keys, also in games whose controls give it the mouse, a joystick or a key cycle.
- Library: a tap on a game opens it even while the library is still updating, a list scrolled by touch stays where you left it, and every game the catalog knows shows its catalog name after a scan.
- Disks page: a disk a game's set adds can be switched on again after switching it off.
- Direct touch works in games that read the mouse port themselves.
- Every game keeps its own CMOS settings.
- The CPU setting sets the slow-mode clock too.
- A drive emptied in a save state shows as empty when it loads.
