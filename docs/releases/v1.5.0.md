# v1.5.0

- New game: a New game button beside search in the library header. Making a game is a few pages: the kind of disk, a Machine page with the machine settings the game will have, then its name. A Creating page shows the game being written; if it can't be (a name already in the games folder), Back returns to the name with every choice kept.
- Library: pull down at the top of the list to refresh it.
- A settings page with a single choice lists that choice's options at once, and settings pages open faster.
- Memory and CPU clock have Custom…: type any memory size from 1 to 64 MB (10 MB on the Marty) and any clock from 1 to 100 MHz.

Install over v1.4.9 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
