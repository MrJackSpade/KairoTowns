# v1.3.1-test.5

Test build of KairoTowns, for FM Towns games. It is not published to Google Play.

- Every setting the catalog gives a game is in its Game settings, where you can change it for that game, including the disk a CD game starts with in Floppy A.
- Startup commands and other text settings can take several lines.
- A long setting value is shortened on its row instead of the setting's name.
- The on-screen keyboard's joystick tab shows a joystick icon.
