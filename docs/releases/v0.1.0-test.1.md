# v0.1.0-test.1

The first test build of KairoTowns, for FM Towns games. It is not published to Google Play.

- Runs FM Towns CD games (CUE, CCD, MDS, ISO) and floppy games (D77, D88).
- Skip memory check, on by default, and machine settings for memory and CPU clock.
- A game library with catalog titles, descriptions and artwork, from a folder of your games; archives are read in place.
- Controller, touch and on-screen keyboard controls, with researched defaults and a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. KairoTowns needs the FM Towns system, DOS, font and dictionary files from your own machine; import them in **Menu › Machine**. Both APK variants have the same features.
