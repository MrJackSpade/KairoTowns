# v1.6.1-test.2

Test build of KairoTowns, for FM Towns games. It is not published to Google Play.

- Split Keyboard: the keyboard splits whenever the space beside the game picture is at least a sixth of the screen's width on each side, such as a 640x400 game at 2x on a 1920x1080 screen. Narrower space leaves the keyboard along the bottom.

Install over v1.6.1-test or v1.6.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
