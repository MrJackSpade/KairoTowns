# v1.4.6

- A boot floppy kept as a BIN, IMG or ISO file beside its CD is recognized as a floppy by its content, loose or inside a ZIP or 7z archive, and goes in drive A when the CD starts (such as Samurai Spirits' boot disk).
- A raw floppy image padded past its disk by its dump loads as that disk.
- A floppy image that cannot be read stops the game with a message naming it, instead of starting with the drive empty.
- The catalog knows 26 more boot, system and user floppies from the FM Towns CD collection, and 24 games now insert their boot or system floppy when their CD starts.

Install over v1.4.5 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
